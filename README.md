# Predição de Intensidade de Chuva em Niterói utilizando Modelos de Classificação

Este projeto aplica técnicas de Inteligência Artificial para a predição de curtíssimo prazo da intensidade de precipitação na cidade de Niterói (RJ). Utilizando dados históricos horários obtidos da estação automática do **INMET (A627)** entre os anos de **2022 e 2025**, o sistema transforma um problema de regressão contínua em um modelo prático de classificação multiclasse voltado para suporte à decisão logística e Defesa Civil.
